# STARGO 追星一站式小助手 · 部署包（v3.3.0）

本目录是可直接托管上线的**纯静态网站**，包含 3 个文件：

| 文件 | 说明 |
|------|------|
| `index.html` | 页面结构（含全部功能入口） |
| `app.js` | 全部交互逻辑（汇率、翻译、歌单、社区、穿搭指南、讨论区、备忘录富文本、个人中心、注册登录等） |
| `style.css` | 样式 |

> 无任何构建步骤、无本地图片/字体依赖、无后端。**任意静态托管都可直接跑。**

---

## 方式一：Netlify Drop（最省事，推荐）

1. 打开 https://app.netlify.com/drop
2. 用 GitHub / Google / 邮箱 任一方式登录（免费）
3. 把本目录（`stargo-deploy-ready` 整个文件夹）**直接拖到页面虚线框**
4. 几秒后自动生成公开链接（形如 `https://xxx.netlify.app`），可一键设为自定义域名

无需命令行、无需配置文件，适合「马上让其他人用上」。

---

## 方式二：GitHub Pages（长期、可协作）

1. 在 GitHub 新建一个仓库（如 `stargo-fan-app`），设为 **Public**
2. 把本目录 3 个文件上传到仓库根目录（可直接拖拽，或 `git push`）
3. 仓库 → **Settings → Pages** → Source 选 `Deploy from a branch` → Branch 选 `main` → 保存
4. 约 1 分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`

> 若仓库名不是根路径托管，页面内相对引用（`style.css` / `app.js`）已自动兼容，无需改路径。
